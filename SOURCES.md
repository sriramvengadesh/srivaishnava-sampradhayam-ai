# Secondary sources

Use other sources only when the primary sources do not adequately
cover the topic. Prefer traditional publications and primary texts
for sampradaya teachings, and reputable academic references for
historical context.

# Research record

For every knowledge entry, record:

- Exact source title
- Author, if identified
- Direct URL to the relevant page or book
- Claims supported by that source
- Whether the source was read or merely discovered in search
- Review status and unresolved questions

Do not mark an entry as reviewed just because a website was found.
