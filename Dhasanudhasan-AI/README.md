
# Sri Vaishnava Knowledge Base

A source-based knowledge collection about Sri Vaishnava Sampradhayam.

## Live website

https://sriramvengadesh.github.io/srivaishnava-sampradhayam-ai/

## Primary sources

1. Koyil.org — https://koyil.org/
2. Acharya.org — https://acharya.org/
3. Sadagopan.org — https://www.sadagopan.org/

## Project structure

- `index.html` — website interface and search
- `data/sources.json` — primary source directory
- `data/categories.json` — knowledge categories
- `data/entries.json` — knowledge entries

## Current capabilities

- Search titles, summaries and keywords
- Filter by category
- Display source links and review status
- Load knowledge files from GitHub Pages

## Important limitations

This version uses keyword matching, not generative AI.
It does not automatically crawl the three source websites.
Knowledge entries must be checked against exact source pages or books.

## Review policy

- `needs_review`: not yet fully verified
- `reviewed`: checked against documented references

Only mark an entry as reviewed after checking its claims and recording
the exact references supporting them.

## Copyright and accuracy

Prefer original sources, short summaries and precise citations.
Respect website access rules and the rights of authors and publishers.
Do not invent citations or claim that a source supports information
unless the relevant page or book has been checked.
